

## Реализованные тесты

В проекте реализованы следующие тесты:

1. `test_add_new_book_add_two_books`  
   Проверяет добавление двух книг в коллекцию.

2. `test_add_new_book_genre_is_empty`  
   Проверяет, что новая книга добавляется без указанного жанра.

3. `test_add_new_book_invalid_name_not_added`  
   Проверяет, что книга с некорректной длиной названия не добавляется.  
   Для проверки используется параметризация:
   - пустое название;
   - название длиной более 40 символов.

4. `test_set_book_genre_valid_genre`  
   Проверяет установку допустимого жанра для существующей книги.

5. `test_set_book_genre_invalid_genre`  
   Проверяет, что жанр, которого нет в списке доступных жанров, не устанавливается.

6. `test_get_books_with_specific_genre`  
   Проверяет получение списка книг с определённым жанром.

7. `test_get_books_for_children`  
   Проверяет получение списка книг, подходящих детям. Книги с возрастным рейтингом в этот список не попадают.

8. `test_add_book_in_favorites`  
   Проверяет добавление существующей книги в избранное.

9. `test_delete_book_from_favorites`  
   Проверяет удаление книги из избранного.
